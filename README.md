# SmartTools

SmartTools is an open-source TypeScript application that brings useful tools together in one place.

## Development

```bash
bun install
bun run dev
```

Run validation with:

```bash
bun run lint
bun run build
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidelines, [SUPPORT.md](SUPPORT.md) for help, and [SECURITY.md](SECURITY.md) for vulnerability reporting.

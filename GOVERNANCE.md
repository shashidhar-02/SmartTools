# Governance

## Project maintainers

SmartTools is maintained by the repository owner and community contributors. Maintainers are responsible for reviewing contributions, maintaining project quality, and making decisions in the best interest of the project.

## Decision making

Routine changes may be approved through normal pull request review. Significant changes should be discussed in an issue or discussion before implementation. Decisions are based on project goals, technical merit, security, maintainability, and community impact.

## Becoming a maintainer

Consistent, constructive contributions may be considered for additional responsibility. Maintainer access is granted at the repository owner's discretion and may be changed when project needs evolve.

## Changes to this document

Governance changes should be proposed through a pull request and reviewed openly.

# Support

## Getting help

For usage questions and general troubleshooting:

1. Check the repository documentation and existing issues.
2. Search closed issues for prior solutions.
3. Open a new GitHub issue using the appropriate template when no answer exists.

When asking for help, include the relevant environment, steps to reproduce, expected behavior, actual behavior, and sanitized logs. Never include secrets or personal data.

## Bugs and feature requests

Use the issue templates for reproducible bugs and well-defined feature requests. For larger proposals, open an issue first so the design can be discussed.

## Security issues

Do not use public issues for security vulnerabilities. Follow the private reporting process in `SECURITY.md`.
